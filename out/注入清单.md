# 注入清单（离线交接版）—— 程序 / 注入位置 / launcher

## 0. C 程序（demo.c）
```c
unsigned char b0;
unsigned char b1;
unsigned char b2;
unsigned char b3;
unsigned char b4;
unsigned char b5;

void main(void) {
    b0 = 0x11;
    b1 = 0x45;
    b2 = 0x14;
    b3 = 0x19;
    b4 = 0x19;
    b5 = 0x81;
    while (1) {
    }
}
```

变量 b0..b5 落在 0xD710..0xD715（--data-base D710）
目标：0xD710 处得到 11 45 14 19 19 81

## 1. 程序（ROP 链）：注入到【左侧地址 E9E0】
`.bin`（34 字节，rGCC 产物，内含内联链数据）:
```
1E FE 10 D7 3E F0 11 45 14 19 19 81 00 00 CA F0 56 90 52 98 EA F0 57 90 53 98 3E F8 2E F4 00 F0 1E 00
```
ROP 链（44 字节 = 真正要注入 0xE9E0 的东西）:
```
42 07 01 00 10 D7 16 0F 01 00 11 45 14 19 19 81 00 00 E2 7D 01 00 00 00 00 00 00 00 00 00 00 00 00 00 42 07 01 00 00 EA 40 07 01 00
```
链结构：`POP ER14 + D710 | POP QR0 + (11 45 14 19 19 81 00 00) | 块写gadget | 12 字节补零 | 循环(取数+枢轴)`
块写 gadget = ROM `0x17DE2` 起（LEA [ER14] ; ST QR0,[EA+] ; ST ER8,[EA+] ; POP QR8 ; POP XR4 ; POP PC）

## 2. launcher：写入【0xD180】
VerC（程序注入 E9E0）:
```
FD 24 D0 E9 7B 23 42
```
VerF（程序注入 E9E0）:
```
FD 24 D0 E9 8F 23 42
```
字节含义：`FD 24` 异常字符前缀 | `D0 E9` = 左地址-10h = E9D0（给 SP）| `7B 23 42` = VerC 枢轴 0x2237A（PC=0x237B→2字节对齐，CSR=2）；VerF 为 `8F 23 42`（枢轴 0x2238E）

## 3. 触发
`→` 然后 `=`

## 4. 期望结果
`0xD710..D715 = 11 45 14 19 19 81`；`0xE9E0` 起为上面的链；SP 应落在 E9E0 附近
